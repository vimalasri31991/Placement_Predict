Regularisation

Regularisation is used to reduce overfitting by adding a penalty to the model coefficients.

What is Regularisation?

Regularisation is a technique used in machine learning to control model complexity and improve generalisation on unseen data.

In this project, Logistic Regression is combined with three regularisation techniques: Ridge, Lasso and Elastic Net.

Ridge Regularisation - L2

Ridge regularisation adds an L2 penalty to the logistic regression objective function.

It reduces the magnitude of model coefficients and helps prevent overfitting.

Lasso Regularisation - L1

Lasso regularisation adds an L1 penalty to the objective function.

L1 regularisation can reduce some coefficients to zero, which can help with feature selection.

Elastic Net

Elastic Net combines both L1 and L2 penalties.

It provides a balance between feature selection and coefficient shrinkage.
