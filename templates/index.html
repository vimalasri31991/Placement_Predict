Placement Prediction Dashboard

Machine Learning based Student Placement Prediction System

Project Overview

This project uses Machine Learning algorithms to predict whether a student is likely to get placed based on academic performance, attendance, aptitude, coding skills, internships, projects, workshops, soft skills and mock interview performance.

Dataset Information

Dataset

Placement Prediction Dataset

Records

50,000 students

Target

PlacementStatus

Problem Type

Binary Classification

Machine Learning Workflow

1

Data Loading

Load the placement dataset and inspect its structure.

2

EDA

Analyze distributions, correlations, missing values and placement status.

3

Preprocessing

Encode categorical features, scale numerical features and handle outliers.

4

ML Models

Train and evaluate multiple Machine Learning algorithms.

Machine Learning Algorithms

Linear Regression

Regression-based baseline for placement outcome prediction.

Logistic Regression

Binary classification model for placement prediction.

Regularisation

L1, L2 and Elastic Net regularisation techniques.

Decision Tree

Tree-based model for student placement classification.

Cost-Complexity Pruning

Decision Tree pruning using cost-complexity analysis.

Random Forest

Ensemble of Decision Trees for classification.

AdaBoost

Boosting algorithm combining weak learners.

Gradient Boosting

Sequential boosting algorithm for placement prediction.

K Calculation

Analyze suitable K values using inertia and silhouette score.

K-Means

Cluster students using K-Means clustering.

K-Means Performance

Evaluate clustering performance using silhouette and ARI.
